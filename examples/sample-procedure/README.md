# 作例：軟性膀胱鏡検査の準備（架空）

[プロンプト集](../../prompts/README.md) を試すための練習用の作例です。手技は一般的な「軟性膀胱鏡検査の準備」ですが、**施設名（架空総合病院）、物品の並べ方のルール、話し手はすべて架空** です。実在の施設の手順ではありません。医学的な手順の正しさは、各施設の基準で確認してください。

## ファイル

1. [sample.srt](sample.srt)：AI自動字幕の出力を想定した、**誤変換を含む** 字幕ファイル（約80秒）
2. [sample-manual.md](sample-manual.md)：字幕を校正し、[手順マニュアル作成プロンプト](../../prompts/02-manual-from-srt.md) で作ったマニュアル
3. [sample-quiz.md](sample-quiz.md)：マニュアルから作った理解度確認クイズ
4. [sample-lyrics.md](sample-lyrics.md)：マニュアルから作った歌詞と曲調指示

## 練習のしかた

sample.srt をダウンロードし、[字幕校正プロンプト](../../prompts/01-subtitle-cleanup.md) と一緒に生成AIに渡してみてください。次のような誤変換が直れば成功です。

- 南西膀胱鏡 → 軟性膀胱鏡
- 完了ライン → 潅流ライン
- 政権 → 生検

「完了ライン、水を流す管ですね」「ナマの組織をとるセイケンです」のように、話し手が言い換えや解説を添えている箇所は、AIが正しい用語を推測しやすくなっています。[話し方のルール](../../docs/02-filming.md) の効果を確かめてみてください。
