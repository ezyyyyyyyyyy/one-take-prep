# one-take-prep

**目線カメラ × 生成AIで、手術準備の教材を「ワンテイク」で作る**

> 第40回日本泌尿器内視鏡・ロボティクス学会総会（JSER2026・神戸）総会賞ビデオ6「Novel Approach」AV6-5
> 「【働き方改革 × AI × 目線カメラ】内視鏡手術の独り立ちを早める術前準備教育システム」の補助資料です。

## これは何か

新しい医師が着任するたびに、上級医は施設固有の手術準備を横について何度も説明しています。手術手技は学会や書籍で学べますが、「この病院の準備」の教材はどこにもありません。

このリポジトリ（GitHub上のファイル置き場）は、指導医が市販の目線カメラ（頭に付けるウェアラブルカメラ）を付けて、いつもどおり口で説明しながら準備するだけで教材を作る方法をまとめたものです。1回の撮影から、次の4種類の教材を作ります。

- **動画教材**：AI自動字幕つき
- **手順マニュアル**：字幕を文章化したもの
- **理解度確認クイズ**：医療安全を重視
- **手順ソング**：歌詞にして記憶に残す

ゴールは **「読んだその日のうちに、1本目の教材を作れる」** ことです。生成AI（指示文に応じて文章や音楽を作るAI）に不慣れな方を想定して書いています。

## 当院での予備的結果

TURBT（経尿道的膀胱腫瘍切除術）の準備を、上級医の監督下で自立して完遂できるようになるまでに要した指導回数は、導入前が平均2.7回（n=3）、導入後が平均1.2回（n=5）でした。学会発表時点の予備的結果であり、単施設・少数例の前後比較であるため、解釈には注意が必要です。現在、同じ作り方で30以上の手技の教材を院内で共有しています。

## 公開方針と、皆さんにお願いしたいこと

このリポジトリには、手術映像、患者情報、院内の運用情報は含めていません。作例はすべて架空です。皆さんが自施設で教材を作る際も、次の点を守ってください。

- 患者さんや他の職員の顔・名前、電子カルテの画面が映らない状況で撮影する
- 生成AIに患者情報を入力しない。所属施設の生成AI利用規程に従う
- AIが作った字幕・マニュアル・クイズ・歌詞は、必ず指導医が内容を確認してから使う
