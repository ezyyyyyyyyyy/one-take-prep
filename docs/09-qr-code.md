# QRコードの作り方とスライドに貼るサイズ

## 作り方

### 方法1：ブラウザの機能を使う（いちばん簡単）

Google Chrome や Microsoft Edge には、表示中のページのQRコードを作る機能があります。公開したページを開き、Chrome はアドレスバーの共有メニュー、Edge はページの右クリックメニューから「QRコードを作成」を選び、画像をダウンロードします。中央に絵が入る場合があるので、必ずスマートフォンで読み取りテストをしてください。

### 方法2：Pythonで作る（高解像度が必要な場合）

```python
# 事前に pip install segno
import segno
qr = segno.make("https://ユーザー名.github.io/リポジトリ名/", error="q")
qr.save("qr.png", scale=30, border=4)   # 印刷・大画面向けの高解像度PNG
qr.save("qr.svg", scale=10, border=4)   # 拡大しても粗くならないSVG
```

`error="q"` は誤り訂正レベル（汚れや欠けに強くする設定）です。スライドで使う場合は M〜Q で十分です。

## スライドに貼るサイズ（16:9、幅33.9cm × 高さ19.1cm のスライドの場合）

- **全スライドに常時表示する場合**：一辺3.0〜3.5cm（白い余白を含む）。右上など、本文と重ならない位置に置きます。
- **案内用のスライド・最終スライド**：一辺8〜10cm。会場の後方からでも読み取れるようにします。

目安として、QRコードを読み取れる距離は「スクリーン上に映ったQRコードの一辺 × 約10倍」です。たとえば幅4mのスクリーンに投影すると、3.5cmのQRコードは約40cmになり、4m程度の距離から読み取れます。後方の席にも届けたい場合は、大きく表示するスライドを1枚入れてください。

## 注意点

- **白い余白（クワイエットゾーン）を切らない**　QRコードの周囲には、セル4個分程度の白い余白が必要です。色付きの背景に重ねる場合も、白い余白ごと貼ります。
- **色を反転させない**　白地に黒が最も確実に読み取れます。
- **短縮URLサービスは使わない**　サービス終了でリンクが切れることがあり、読み取った人がリンク先を確認しにくくなります。
- **リポジトリ名を変えない**　Pages のURLが変わり、印刷・配布済みのQRコードが使えなくなります。
- **事前に投影して読み取りテストをする**　会場の後方に相当する距離から、スマートフォンで読み取れるか確認してください。
