# 今日やること：最短で1本目を作る

撮影から字幕つき動画の完成まで、慣れれば1手技あたり約30分です。手順マニュアル・クイズ・歌は、翌日以降でかまいません。まずは動画1本を作ることを目指してください。

## 用意するもの

- **目線の高さで撮れるカメラ**：ウェアラブルカメラが理想ですが、最初はスマートフォンと首掛けホルダーでも始められます（[撮影のコツ](02-filming.md)）
- **AI自動字幕機能つきの動画編集ソフト**：著者らは PowerDirector 365 を使っています（[字幕生成](03-subtitles.md)）
- **生成AIチャット**：Claude、ChatGPT、Gemini、Microsoft Copilot など。所属施設で利用が認められているものを使ってください
- **院内で教材を共有する場所**：Teams、院内の共有フォルダなど

## 手順

1. **題材を1つ決める**　5〜10分で終わる、毎回同じ説明をしている準備が向いています（例：膀胱鏡検査の準備、尿道カテーテル留置の準備）。
2. **撮影の許可と映り込みを確認する**　患者さんの入室前など、患者情報や他の職員の顔が映らない状況を選びます。
3. **カメラを付けて10秒だけ試し撮りする**　手元が画面の中央〜下寄りに入っているか、声が聞き取れるかを確認します。
4. **ワンテイクで撮影する**　最初に「〇〇の準備を行います」と目的を言い、あとはいつもどおり説明しながら準備します。言い間違えても止めずに言い直せば大丈夫です。器具名は2回言うのがコツです（[話し方のルール](02-filming.md)）。
5. **AI自動字幕を作り、字幕ファイル（SRT）で書き出す**（[字幕生成](03-subtitles.md)）
6. **生成AIで字幕の誤変換を直す**　[字幕校正プロンプト](../prompts/01-subtitle-cleanup.md) と字幕ファイルを生成AIに渡します。
7. **直した字幕を動画に戻して書き出す**　見やすさのため1.2〜1.5倍速にするのもおすすめです。
8. **指導医が通して確認し、院内で共有する**
