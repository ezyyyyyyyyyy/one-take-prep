# 撮影のコツ

## 機材の選び方

著者らは Insta360 GO Ultra（小型のウェアラブルカメラ）を使っていますが、次の条件を満たせば機種は問いません。

- 目線の高さで、手元を含む広い範囲（広角）が撮れる
- 両手が空く（ハンズフリーで装着できる）
- 準備1回分（10〜15分程度）を連続で録画できる
- 内蔵マイクで話し声がはっきり録れる

最初の1本は、スマートフォンを首掛けホルダーで胸元に付ける方法でも十分です。

## 装着のしかた

- 帽子やヘッドバンドに付属のマウントで固定し、レンズはやや下向きにします。
- 手元が画面の中央〜下寄りに入るよう、10秒の試し撮りで確認してから本番に入ります。
- カメラは清潔野に入れず、清潔な器具や術野に触れない位置に付けます。
- マスク越しでも声が録れるか、試し撮りで聞いて確認します。

## 撮影前の確認

- 撮影と院内共有について、所属部署の許可を得ておく
- 患者さんの入室前など、患者情報が映らない状況で撮る
- 電子カルテ画面、ホワイトボード、検体ラベルなどが映り込まない向きにする
- 他の職員が映る場合は、事前に了承を得る

## 話し方のルール

AI自動字幕の精度は、話し方で大きく変わります。次の4つを意識してください。

1. **最初に動画の目的を言う**　例：「膀胱癌に対するTURBTの道具の準備を行います。」
2. **固有名詞や器具名は、教えるように繰り返し声に出す**　器具名を言ったら、少し間をおいてもう一度言います。
3. **同じ操作を、別の表現で言い換えてもう一度説明する**　言い換えがあると、字幕が誤変換しても意味を復元しやすくなります。
4. **同音異義語には解説を添える**　例：「生検、ナマの組織検体をとるセイケンです。」（「政権」「聖剣」などへの誤変換を防ぎます）

さらに、次の点も効果的です。

- 動作の前に「今から〜します」と言ってから手を動かす
- 安全上の注意は「ここ、注意です」と前置きして言う
- 数字は単位まで言う（「20ミリリットル」など）

## ワンテイクで撮る

- 言い間違えても止めず、「失礼、〇〇です」と言い直して続けます。不要な部分は編集でカットできます。
- 1手技を1本の動画にします。長くなる場合は工程ごとに分けてもかまいません。
