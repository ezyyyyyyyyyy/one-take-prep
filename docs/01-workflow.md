# 全体の流れ

```text
 ① 撮影（目線カメラ・ワンテイク）
        │
 ② AI字幕化 ─────────▶ 動画教材（字幕つき）
        │ 字幕ファイル（SRT）
 ③ 手順マニュアル化 ─▶ 手順マニュアル（紙・院内チャット）
        │
        ├─ ④ クイズ化 ─▶ 理解度確認クイズ（NotebookLM）
        └─ ⑤ 作詞・作曲 ▶ 手順ソング（Claude ＋ Suno）
```

## 考え方：なぜ「準備」を教材にするのか

能力は、持ち運べるかどうかで2種類に分けられます（Groysberg ら, Harvard Business Review, 2006 の枠組み）。

- **Portable（どこでも通用する）**：手術手技など。学会・書籍・動画の教材が豊富にあります。
- **In-house（その施設でしか通用しない）**：準備・器具のセッティングなど。教材は存在せず、上級医が横について口頭で教えるしかありません。

限られた指導時間は手術手技に使い、施設固有の準備は教材として外に出す、というのがこの仕組みの狙いです。

## ポイント：字幕ファイルがすべての「原本」

撮影は1回だけです。AI自動字幕で作った字幕ファイル（SRT：字幕の文章と表示時刻を記録したテキストファイル）を校正すれば、それが手順マニュアル・クイズ・歌詞のすべての元になります。字幕の校正を丁寧に行うほど、後の教材の質が上がります。

## 各ステップの概要

1. **撮影**　指導医が目線カメラを付け、いつもどおり説明しながら準備します。撮影スタッフもシナリオの打ち合わせも不要です。→ [撮影のコツ](02-filming.md)
2. **字幕化**　動画編集ソフトのAI自動字幕で文字起こし（音声を文字に変換すること）を行い、生成AIで誤変換を直します。→ [字幕生成](03-subtitles.md)
3. **手順マニュアル化**　校正した字幕ファイルを生成AIに渡し、物品・手順・安全確認の形に整理させます。→ [手順マニュアル](04-manual.md)
4. **クイズ化**　手順マニュアルを NotebookLM に読み込ませ、理解度確認クイズを作ります。→ [クイズ](05-quiz.md)
5. **歌にする（任意）**　手順マニュアルから生成AIに歌詞を作らせ、Suno で曲にします。→ [手順ソング](06-song.md)

## 人が必ず確認する3か所

生成AIは、もっともらしい誤り（ハルシネーション）を出力することがあります。次の3か所は必ず指導医が確認してください。

- 校正後の字幕（特に左右・「入れる／抜く」・数字）
- 手順マニュアル（字幕にない内容が足されていないか）
- クイズの正解と解説

## 役割分担の例

撮影と最終確認は指導医が行います。字幕の校正以降はプロンプト（AIへの指示文）を定型化しているので、医師以外のスタッフでも作業できます。
