# NotebookLMで理解度確認クイズを作る

NotebookLM は Google の AI ノートです。アップロードした資料（ソース）だけを根拠に回答や問題を作るため、教材の内容から外れにくいのが特徴です。

## 手順

画面の表記はバージョンによって異なります。

1. NotebookLM（<https://notebooklm.google.com>）を開き、新しいノートブックを作る
2. ソースとして、手順マニュアルと校正済みの字幕ファイルを追加する
3. 画面右側の「Studio」から「クイズ」を選ぶ
4. カスタマイズ欄があれば、問題数・難易度を選び、[クイズ用プロンプト](../prompts/03-notebooklm-quiz.md) の指示文を貼り付ける
5. 生成されたクイズを指導医が解いて、正解と解説が正しいか確認する
6. ノートブックを共有する、または問題をテキストにして院内で配布する

共有の方法と範囲は、Googleアカウントの種類（個人／組織）や施設の規程によって異なります。

## NotebookLMを使わない方法

生成AIチャットに [クイズ用プロンプト](../prompts/03-notebooklm-quiz.md) の「チャットAI版」を使って4択問題を作らせ、Microsoft Forms などの院内で使えるフォームに貼り付ける方法もあります。

## 良いクイズにするコツ

- **医療安全に関わる確認事項を優先して出題する**（アレルギー確認、熱傷予防、物品の数の確認など）
- **教材に書かれている事実だけから出題する**　施設や流派で考え方が分かれる内容は出題しません。
- **誤りの選択肢には、実際に起こりやすい間違いを使う**　間違えたときに学びになります。
- **解説には根拠となる手順と動画の時刻を書く**

作例：[架空の「軟性膀胱鏡検査の準備」クイズ](../examples/sample-procedure/sample-quiz.md)
