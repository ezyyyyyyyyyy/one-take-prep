# 字幕から手順マニュアルを作る

校正済みの字幕ファイル（SRT）を生成AIに渡し、新任医師が読んで準備できる手順マニュアルに整理させます。

## 手順

1. 生成AIチャットを開き、[手順マニュアル作成プロンプト](../prompts/02-manual-from-srt.md) を貼り付ける
2. 【手技名】などの【 】部分を書き換え、校正済みの SRT ファイルを添付して送信する
3. 出力された【要確認】の一覧を指導医に確認してもらい、修正する
4. 作成日と確認した指導医の名前を書き、紙や院内チャットで共有する

## マニュアルに入れる項目

- 目的
- 必要物品
- 開始前の確認事項
- 手順（番号付き、動画の該当時刻つき）
- 安全確認ポイント
- よくある間違い
- 作成日・確認者

動画の該当時刻を書いておくと、マニュアルを読んで分からない箇所だけ動画で確認できます。

## うまく作るコツ

- **字幕にない内容を足させない**　生成AIは一般的な知識で手順を補うことがあります。補った箇所は（補足）と明記させ、指導医が残すかどうか判断します。
- **表は使わせない**　院内チャット（Teams など）に貼り付けると、表の罫線や列が崩れることがあります。見出しと箇条書きで作らせると、どこに貼っても読みやすくなります。
- **版を管理する**　器具や手順が変わったら撮り直し、作成日を更新します。

作例：[架空の「軟性膀胱鏡検査の準備」マニュアル](../examples/sample-procedure/sample-manual.md)
