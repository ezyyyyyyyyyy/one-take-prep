# AI文字起こし・字幕生成

文字起こし（音声認識：話し声をAIが文字に変換すること）で字幕を自動生成し、生成AIで誤変換を直します。

## 手順（著者らの例：PowerDirector 365）

メニュー名はソフトのバージョンによって異なります。他の動画編集ソフトでも、AI自動字幕機能があれば同じ流れで作れます。

1. 撮影した動画を編集ソフトに読み込む
2. AI自動字幕（音声から字幕を自動生成する機能）を、言語「日本語」で実行する
3. 字幕を SRT 形式（字幕の文章と表示時刻を記録したテキストファイル）で書き出す
4. 生成AIに [字幕校正プロンプト](../prompts/01-subtitle-cleanup.md) と SRT ファイルを渡し、誤変換を直させる
5. 校正済みの SRT を編集ソフトに読み込み直す
6. 動画を通して見て、字幕と映像が合っているか確認する
7. 必要に応じて1.2〜1.5倍速にして書き出す

## 校正で直すもの

- 医学用語・器具名の誤変換（例：「政権」→「生検」、「完了ライン」→「潅流ライン」）
- 「えーと」「あの」などの言いよどみ（フィラー）
- 長すぎる行の分割（1行27文字程度まで）

## 必ず人が確認するもの

次のような誤変換は、安全に直結します。生成AIにも推測で直させず、【要確認】として残させます。

- 左右（右／左）
- 操作の向き（入れる／抜く、開く／閉じる）
- 否定（切る／切らない）
- 数字と単位

## 注意

- AI自動字幕の機能によっては、音声が外部のサーバーに送られて処理されます。施設の規程を確認してください。
- 字幕ファイルにも患者情報が含まれないようにしてください。

練習用の誤変換入り字幕ファイルは [作例](../examples/sample-procedure/README.md) にあります。
