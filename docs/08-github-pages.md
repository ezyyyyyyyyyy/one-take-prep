# GitHub Pagesでの公開手順

GitHub Pages は、GitHub のリポジトリ（ファイル置き場）に置いた文書を、そのままWebサイトとして公開する無料の機能です。スマートフォンでも読みやすく、QRコードの読み込み先として向いています。

## 公開の手順

1. GitHub のアカウントを作る
2. 右上の「＋」→「New repository」で新しいリポジトリを作る
   - Repository name：URLの一部になります（例：`one-take-prep`）。後から変えるとURLが変わり、QRコードが使えなくなるので、最初に決めておきます。
   - 公開範囲：**Public** を選びます（無料プランで Pages を使うには Public が必要です）。
3. リポジトリの画面で「Add file」→「Upload files」を選び、ファイルやフォルダをドラッグ＆ドロップして「Commit changes」を押す
4. 「Settings」→ 左メニューの「Pages」を開く
5. 「Build and deployment」の Source で「Deploy from a branch」を選び、Branch を「main」、フォルダを「/(root)」にして「Save」を押す
6. 数分待つと、同じ画面に公開URL（`https://ユーザー名.github.io/リポジトリ名/`）が表示される

README.md がトップページになり、他の Markdown（見出しや箇条書きを記号で書く文書形式）のファイルも自動でWebページに変換されます。見た目は `_config.yml` の `theme` で変えられます。

## 注意点

- **一度アップロードしたファイルは履歴に残ります**　後から削除しても、過去の履歴から見られる可能性があります。院内資料や患者情報を含むファイルは、一時的にでもアップロードしないでください。
- **メールアドレスの公開を防ぐ**　「Settings」→「Emails」で「Keep my email addresses private」をオンにしておくと、更新履歴に個人のメールアドレスが載りません。
- **ファイルサイズの上限**　ブラウザからのアップロードは1ファイル25MBまでです。動画ファイルは事前に圧縮してください。
- **公開範囲**　Public のリポジトリと Pages は、誰でも閲覧できます。

## 自施設用に複製する場合

このリポジトリの解説文書は CC BY 4.0、プロンプト集は CC0 1.0 なので、複製して自施設向けに書き換えて使えます。ただし、自施設の院内情報は公開リポジトリに載せないでください。院内向けには、院内の共有フォルダや Teams などで管理することをおすすめします。
