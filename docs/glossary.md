# 用語集

- **生成AI**：指示文に応じて、文章・画像・音楽などを新しく作り出すAI。Claude、ChatGPT、Gemini、Microsoft Copilot、Suno など。
- **プロンプト**：生成AIへの指示文。何を、どのような形式で出力してほしいかを書きます。
- **LLM（大規模言語モデル）**：大量の文章で学習し、文章を理解・生成するAIの仕組み。生成AIチャットの中核です。
- **ハルシネーション**：生成AIが、事実と異なる内容をもっともらしく出力すること。医療教材では必ず人が確認します。
- **文字起こし（音声認識）**：話し声をAIが文字に変換すること。
- **AI自動字幕**：文字起こしの結果を、動画の表示時刻つきの字幕として自動で作る機能。
- **SRT**：字幕の番号・表示時刻・文章を記録したテキストファイルの形式。多くの動画編集ソフトで読み書きできます。
- **フィラー**：「えーと」「あの」などの言いよどみ。字幕からは削除します。
- **NotebookLM**：Google の AI ノート。アップロードした資料（ソース）だけを根拠に、要約やクイズを作ります。
- **ソース**：NotebookLM に読み込ませる資料。ここでは手順マニュアルと字幕ファイル。
- **Suno**：歌詞と曲調の指示から、歌入りの楽曲を作るAI。
- **スタイル（Suno）**：曲のジャンル、テンポ、声の種類などを英語で指定する欄。
- **ウェアラブルカメラ**：頭や体に付けて、ハンズフリーで撮影できる小型カメラ。
- **リポジトリ**：GitHub 上のファイル置き場。変更の履歴も記録されます。
- **GitHub Pages**：リポジトリに置いた文書を、Webサイトとして無料で公開する GitHub の機能。
- **Markdown**：見出しや箇条書きを記号で書く文書形式。このリポジトリの文書はすべて Markdown です。
- **CC BY 4.0**：出典を表示すれば、改変・再配布・商用利用を含めて自由に使えるライセンス。
- **CC0 1.0**：権利を放棄し、クレジット表記なしで自由に使えるようにする宣言。
