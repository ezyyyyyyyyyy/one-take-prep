# Sunoで手順ソングを作る

手順マニュアルのエッセンスを歌詞にし、Suno（歌詞と曲調の指示から歌入りの楽曲を作るAI）で曲にします。器具の名前、安全確認、施設固有のルールが自然に頭に入ることを狙っています。歌は任意ですが、繰り返し聞くことで記憶の取っかかりになります。

## 手順

1. 生成AIチャットに [作詞プロンプト](../prompts/04-suno-lyrics.md) と手順マニュアルを渡し、歌詞と曲調指示を作らせる
2. 指導医が歌詞を確認する（手順の順番、安全確認の内容）
3. Suno を開き、歌詞を自分で入力するモード（カスタムモード）を選ぶ
4. 歌詞欄に歌詞を、スタイル欄に曲調指示（英語）を貼り付けて生成する
5. 何曲か生成し、聴き比べて選ぶ

曲調指示の例は [曲調指示の例](../prompts/05-suno-style.md) にまとめています。

## うまく作るコツ

- **歌詞に入れる内容を3種類に絞る**：器具の固有名詞、医療安全のポイント、施設固有のルール
- **最重要の安全ポイントはサビに入れて繰り返す**
- **読み間違えやすい漢字はひらがな・カタカナで書く**　AIは医学用語の漢字を誤読することがあります。
- **実在の歌手名・曲名をスタイル欄に書かない**　ジャンル、テンポ、声の種類で指定します。

## 権利について

Suno で作った楽曲の権利は、生成した時点の契約プランによって異なります。院内で使う、公開するなどの目的に応じて、Suno の最新の利用規約を確認してください。施設固有の情報を含む歌は、院内限定で使うことをおすすめします。
