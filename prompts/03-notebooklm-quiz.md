# 理解度確認クイズのプロンプト

## A. NotebookLM 用

NotebookLM で手順マニュアルと字幕ファイルをソースに追加し、「Studio」→「クイズ」のカスタマイズ欄に貼り付けます。

```text
新任医師が【手技名】の準備手順を正しく覚えているかを確認するクイズにしてください。
・医療安全に関わる確認事項を優先して出題する
・ソースに書かれている事実だけから出題する
・施設や考え方によって答えが分かれる内容は出題しない
・誤りの選択肢には、実際に起こりやすい間違いを使う
・解説では、正解の根拠となる手順を示す
```

## B. チャットAI版（NotebookLM を使わない場合）

手順マニュアルを添付して使います。出力を Microsoft Forms などに貼り付ければ、院内でクイズとして配布できます。

```text
添付の手順マニュアルをもとに、【手技名】の準備についての理解度確認クイズを【5】問作ってください。

【条件】
・4択問題とし、正解は1つにする
・医療安全に関わる確認事項を優先して出題する
・マニュアルに書かれている事実だけから出題する
・施設や考え方によって答えが分かれる内容は出題しない
・誤りの選択肢には、実際に起こりやすい間違いを使う
・正解の位置（A〜D）が偏らないようにする

【出力形式（1問ごと）】
問題：
A.
B.
C.
D.
正解：
解説：（根拠となる手順と、マニュアルに書かれた動画の時刻）
```

## ヒント

- 指導医が実際に解いてみて、正解と解説が正しいか確認してください。
- 問題数は5〜10問程度が、繰り返し解いてもらいやすい分量です。
