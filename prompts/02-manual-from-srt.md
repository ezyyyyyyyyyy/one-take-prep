# 手順マニュアル作成プロンプト

校正済みの字幕ファイル（SRT）から、新任医師向けの手順マニュアルを作ります。

```text
あなたは手術室の教育担当者です。
添付の字幕ファイル（SRT形式）は、指導医が【手技名】の準備を口頭で説明しながら行った動画の字幕です。
この字幕だけを根拠に、【対象：例 新任医師】向けの手順マニュアルを作ってください。

【構成】
1. 目的（1〜2行）
2. 必要物品（種類ごとに箇条書き）
3. 開始前の確認事項
4. 手順（番号付き。各手順の末尾に動画の時刻を［分:秒］で付ける）
5. 安全確認ポイント（各項目の先頭に ▲ を付ける）
6. よくある間違い
7. 作成日・確認した指導医（空欄でよい）

【ルール】
・字幕にない内容は追加しない。一般的な知識で補った場合は、文末に（補足）と書く
・字幕から判断できない点は【要確認】と書き、最後に一覧にする
・左右、入れる／抜く、量や数字に関わる記載は字幕のとおりに書き、推測で変えない
・表は使わず、見出しと箇条書きで書く（院内チャットに貼っても崩れないようにするため）
・である調で、1文は短くする

【出力形式】
Markdown
```

## ヒント

- 出力の最後にある【要確認】の一覧を、指導医に確認してもらってください。
- 院内の配布形式（Word など）に合わせたい場合は、「出力形式」を書き換えます。
