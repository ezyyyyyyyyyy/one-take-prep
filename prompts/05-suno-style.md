# 曲調指示の例（Suno のスタイル欄）

Suno のスタイル欄には、ジャンル、テンポ、声の種類などを英語で短く書きます。そのままコピーして使えます。

## 明るく覚えやすい（迷ったらこれ）

```text
upbeat J-pop, catchy chorus, bright female vocal, clear Japanese pronunciation, 128 BPM
```

## 落ち着いて聞ける

```text
acoustic folk, warm male vocal, gentle guitar, slow tempo, clear diction
```

## 気分を上げる

```text
energetic rock, driving drums, powerful vocal, anthemic chorus, 140 BPM
```

## アニメ主題歌風

```text
anime opening style, fast tempo, energetic band sound, bright vocal, dramatic chorus
```

## 80年代シティポップ風

```text
80s Japanese city pop, funky bass, smooth vocal, synth, groovy
```

## 演歌風

```text
enka, dramatic strings, vibrato male vocal, slow tempo, emotional
```

## コツ

- **clear Japanese pronunciation**（はっきりした日本語の発音）を入れると、歌詞が聞き取りやすくなります。
- **テンポ（BPM：1分間の拍数）** を指定すると、曲の速さを調整できます。
- **実在の歌手名・曲名は書かない**　ジャンルや声の特徴で指定します。
- 同じ歌詞で何曲か生成し、聞き取りやすさで選ぶのがおすすめです。
