# プロンプト集

生成AIへの指示文（プロンプト）を、コピーしてそのまま使える形でまとめています。著者らは Claude で使っていますが、ChatGPT、Gemini、Microsoft Copilot などでも使えます。

このフォルダのプロンプトは [CC0 1.0](LICENSE) です。クレジット表記なしで、自由に書き換えて使ってください。

## 一覧

1. [字幕の校正](01-subtitle-cleanup.md)：AI自動字幕の誤変換・言いよどみを直す
2. [手順マニュアルの作成](02-manual-from-srt.md)：字幕から手順マニュアルを作る
3. [理解度確認クイズの作成](03-notebooklm-quiz.md)：NotebookLM 用とチャットAI用
4. [作詞](04-suno-lyrics.md)：手順マニュアルから Suno 用の歌詞を作る
5. [曲調指示の例](05-suno-style.md)：Suno のスタイル欄に入れる英語の指示

## 使い方

1. コードブロック（灰色の枠）の中身をすべてコピーする
2. 【 】の部分を、自分の手技や施設に合わせて書き換える
3. 生成AIチャットに貼り付け、必要なファイル（字幕やマニュアル）を添付して送信する

## 守ってほしいこと

- 患者情報を入力しない。所属施設の生成AI利用規程に従う
- 出力は必ず指導医が確認してから教材として使う
