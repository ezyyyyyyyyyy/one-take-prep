# 作詞プロンプト（Suno 用）

手順マニュアルから、Suno にそのまま貼り付けられる歌詞を作ります。生成AIチャットに手順マニュアルを添付して使います。

```text
あなたは医療教育用の作詞家です。
添付の手順マニュアルをもとに、【手技名】の準備を覚えるための歌詞を作ってください。

【必ず入れる内容】
・器具の名前：【例：軟性膀胱鏡、潅流ライン】
・医療安全のポイント：【例：光源をつけたまま先端を置きっぱなしにしない】
・施設固有のルール：【例：物品は左から使う順に並べる】

【条件】
・長さは2〜3分程度
・構成：[Intro] [Verse] [Pre-Chorus] [Chorus] [Verse] [Chorus] [Bridge] [Chorus] [Outro]
・セクション名は [ ] で囲む
・最も大切な安全ポイントはサビ（Chorus）に入れ、繰り返す
・手順はマニュアルの順番どおりに歌う
・マニュアルにない内容は追加しない
・読み間違えやすい漢字は、ひらがなかカタカナで書く（例：潅流→かんりゅう）
・覚えやすく、口ずさみやすい言葉にする

【出力】
1. Suno の歌詞欄にそのまま貼れる歌詞
2. Suno のスタイル欄に入れる英語の曲調指示（短く）
3. 歌詞に入れた器具名・安全ポイント・施設ルールの一覧（確認用）
```

## ヒント

- 出力3の一覧を見て、入れたい内容が漏れていないか、手順の順番が正しいかを指導医が確認してください。
- 曲調を変えたい場合は [曲調指示の例](05-suno-style.md) を参考に、スタイル欄だけ書き換えます。
- 施設固有の情報を含む歌は、院内限定で使うことをおすすめします。
